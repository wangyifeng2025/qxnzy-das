# 任务：从文本中抽取填报记录

输入是文件正文片段。请抽取所有能确定的记录，每个字段都必须能在 `source_text` 中找到依据。

## 输出格式

```json
{
  "records": [
    {
      "values": {"字段代码": "原文中的值"},
      "evidence": "原文中连续的一段文字，必须逐字复制",
      "confidence": 0.85
    }
  ]
}
```

## 规则

1. `evidence` 必须是输入原文中逐字存在的连续片段，包含该记录的全部字段依据；程序会核验，核验失败的字段会被丢弃。
2. 不要输出原文没有的字段。日期、数字保持原文写法。
3. 一段文字包含多条记录（例如名单、表格化的段落）时，拆成多条；无法拆分时宁可少抽。
4. 同一份材料中的表头、页眉、页码、填表说明不需要输出。
5. `confidence` 取 0 到 1，表示字段值是否明确。
6. 如果没有任何可抽取的记录，返回 `{"records": []}`。
