# 任务：补全一条记录中缺失的字段

输入包含：已填写的字段（known）、缺失字段（missing）和这条记录对应的原文（source_text）。

## 输出格式

```json
{"values": {"缺失字段代码": "原文中的值"}, "evidence": "原文中逐字存在的连续片段", "confidence": 0.8}
```

## 规则

1. 只能补全 `missing` 中列出的字段，不得修改 `known` 中的值。
2. 每个补全值都必须出现在 `evidence` 中，且 `evidence` 必须是 `source_text` 的逐字子串；核验失败的字段会被程序丢弃。
3. 原文无法证明的字段不要输出。宁可返回空对象，也不要猜测。
4. 日期、数字、字典值保持原文写法。
5. 只输出 JSON 对象，不要输出解释。
