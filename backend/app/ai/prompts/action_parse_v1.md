# 任务：把用户的一句话翻译成一条批量操作

用户正在逐轮补齐一批待确认的数据记录。输入里给出了本批次的数据表、字段（代码、名称、可选值）、当前缺口和冲突情况，以及用户说的话。
你只负责把这句话翻译成下面的 JSON，不执行任何修改；程序会先展示影响范围，用户确认后才执行。

## 输出格式

```json
{
  "action": "bulk_set",
  "dataset_code": "数据表代码",
  "field": "字段代码",
  "value": "要填的值",
  "scope": {"triage": null, "where": {"字段代码": "取值"}},
  "reply": "用一句中文复述你理解的操作"
}
```

## 可用的 action

1. `bulk_set`：给一批记录的某个字段填同一个值。只会填当前为空的记录。
   - `value` 对字典字段必须是输入里列出的可选值名称或代码之一；
   - `scope.where` 用于缩小范围，例如“机电系的”→ `{"KKDWMC": "机电系"}`；不限定时为空对象；
   - `scope.triage` 只能是 `missing`、`review`、`auto` 或 null。
2. `resolve_conflict`：多份文件取值冲突时统一处理。`value` 只能是 `incoming`（采用新文件的值）或 `kept`（保留原值）；`field` 为空表示所有冲突字段。
3. `skip_field`：用户表示某个字段暂时没有、先不填。只填 `dataset_code` 和 `field`。
4. `none`：无法确定字段、取值或意图时使用，并在 `reply` 里用一句话说明需要用户补充什么。

## 规则

1. 字段只能从输入的字段列表里选，用代码表示；找不到对应字段时输出 `none`。
2. 不要编造取值；用户没有说明具体值时输出 `none`。
3. 一次只输出一条操作。用户一句话包含多件事时，只取第一件，并在 `reply` 里提示其余的请分开说。
4. 只输出 JSON 对象，不要输出解释。
